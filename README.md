# Info
This Java program uses SQLite to keep track of products. It can add products, show the inventory, and update a product's price or quantity.
# How to use
- Open the project in IntelliJ.
- Make sure the SQLite JDBC driver is added.
- Run Main.java.
The database is named inventory.db and stores each product's ID, name, category, price, and quantity.
